# 平台規格（IG / FB）

> 平台規格會變動，正式發布前請對照官方最新說明。以下是保守、通用的安全值。

| 項目 | Reels（IG / FB） | 動態貼文（IG / FB） |
|---|---|---|
| 比例 | 9:16 | 4:5（IG）、1:1 或 16:9（FB） |
| 解析度 | 1080×1920 | 1080×1350 / 1080×1080 / 1920×1080 |
| 影格率 | 30 fps | 30 fps |
| 編碼 | H.264 + AAC，yuv420p，faststart | 同左 |
| 建議長度 | 15–60 秒（上限以平台為準） | 視內容 |
| 音量 | 約 -16 LUFS | 約 -16 LUFS |
| 字幕安全區 | 避開上方約 14%、下方約 20%（被介面蓋住） | 靠下 10% 內 |

Podcast 長片另存一份 16:9 原比例版本供 FB / YouTube。
